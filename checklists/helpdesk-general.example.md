# Общий HelpDesk

## summary
Кратко опишите проблему (станет заголовком тикета)

## description
Опишите проблему подробно: что происходит, что ожидалось

## priority
Укажите приоритет: Low / Medium / High / Critical

## contact_email
Укажите email для обратной связи

## environment
Укажите окружение: production / staging / development

## error_message
Вставьте текст ошибки из логов (или напишите «нет»)
